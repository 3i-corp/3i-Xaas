# iii-card

Separate prepaid Virtual Card domain boundary. V1 target: virtual-only card with Visa or Mastercard subject to issuer/program selection and approval. No physical card.

Owns issuer adapter integration, card lifecycle metadata, authorization/clearing/reversal events and card controls. Issuer owns card credentials. Store only opaque issuer references/tokenized metadata and permitted masked display data; never PAN/CVV.

**State:** planning placeholder, no issuer selected and no issuance enabled.
