# iii-wallet

Wallet domain boundary for account ownership, currency-specific subaccounts, immutable balanced ledger, holds, available/pending/restricted balances, top-up credit posting, limits and transaction history.

**V1 scope:** Thailand, THB, incoming PromptPay top-up only. No withdrawal/payout, P2P or seller settlement. This placeholder does not replace existing Wallet ADR or authorize schema changes.
